# The Sword and Pen - Digital Scripture Study Tool

This application is a modern Bible study tool built with Next.js, Tailwind CSS, and Firebase. It is designed for deep scripture study with features like verse highlighting, persistent categorization, a prayer journal, and stylus-optimized sketching.

## Project Storage & Hosting

- **Environment**: This project is developed and stored within **Firebase Studio**.
- **Backend & Database**: User data (annotations, categories, bookmarks, and journal entries) is stored securely in **Google Firebase Firestore**.
- **Authentication**: User accounts are managed via **Firebase Authentication**.
- **Hosting**: The live application is deployed using **Firebase App Hosting**.

## Key Features

- **Multi-Translation Support**: Access KJV, NIV, ESV, NLT, and more.
- **Smart Highlighter**: Categorize verses into themes like Promise, Grace, and Love, or create your own.
- **Integrated Journal**: Link your prayers and reflections directly to scripture references.
- **Study Workspace**: A dedicated side panel with a scratchpad for notes and a high-precision sketchpad for drawings/diagrams.
- **Cross-Reference Engine**: Discover related scriptures with one-click previews.
- **AI Insights**: Generate scholar-level insights based on your personal study notes using Genkit.
